Hi, I'm **Giandomenico Riceputi**
I try to build web experiences that are both beautiful and accessible, where **everyone can find their place**.

## Welcome to My Digital Space

I'm a front-end developer who cares deeply about making websites that work well for all kinds of users. This website is where I share my learning process, personal projects, and thoughts about web accessibility and CSS.

The name **"Accessibility Bubbles"** came from noticing how understanding about accessibility often surfaces gradually—like bubbles rising to the surface. Each project and article represents a small insight I've gathered along the way.

## Areas I'm Exploring

### Web Accessibility
I'm learning how to make the web more welcoming to everyone. I'm working with semantic HTML, ARIA, and inclusive patterns to create experiences that more people can use comfortably.

### CSS & Front-End Development
I enjoy working with CSS to create responsive, user-friendly interfaces. I'm always experimenting with layout techniques and thinking about how to make websites both useful and pleasant to use.

### Sharing What I Learn
I write about my discoveries because I've learned so much from others sharing their knowledge. Whether it's working through an accessibility challenge or finding a helpful CSS approach, I like passing along things that might help others too.

## How I Try to Work

- **Start with accessibility** - Thinking about inclusivity from the beginning
- **Build progressively** - Creating websites that work in different situations
- **Keep learning** - There's always more to understand and improve
- **Share with others** - Learning works better when we do it together

## Outside of Coding

When I'm not working on websites, I might be:

- Trying out new web tools and approaches
- Learning about design and how people use websites
- Participating in web development communities
